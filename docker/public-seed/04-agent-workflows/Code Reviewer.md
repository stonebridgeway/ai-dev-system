# Code Reviewer

Use when: нужно сделать review diff, PR или локальных изменений.

## Review stance

Findings first.

Prioritize:

- bugs;
- regressions;
- security issues;
- data loss risks;
- missing tests;
- broken UX;
- performance risks.

## Output format

1. Findings ordered by severity.
2. Open questions.
3. Short summary.
4. Test gaps.
