# Repo Onboarding

Use when: агент впервые открывает репозиторий или должен быстро понять проект.

## Steps

1. Найти README, package files, config files.
2. Найти `AGENTS.md` или локальные инструкции.
3. Определить стек и команды.
4. Найти entrypoints.
5. Найти tests и quality gates.
6. Составить карту проекта.

## Output

- Что это за проект.
- Как запустить.
- Где основные модули.
- Какие команды проверки.
- Какие риски и неизвестные.
