# Feature Builder

Use when: нужно добавить новую функцию в существующий проект.

## Steps

1. Уточнить expected behavior из задачи и знаний.
2. Найти существующие patterns.
3. Спланировать минимальное изменение.
4. Реализовать.
5. Добавить или обновить tests.
6. Запустить relevant checks.
7. Проверить UX, если есть frontend.

## Guardrails

- Не переписывать архитектуру без причины.
- Не добавлять новую dependency без пользы.
- Не менять unrelated behavior.
- Не оставлять непроверенные happy-path-only решения.
