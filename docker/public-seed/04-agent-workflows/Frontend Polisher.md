# Frontend Polisher

Use when: нужно улучшить frontend UI/UX.

## Principles

- Делать рабочий интерфейс, не landing page, если пользователь просит app/tool.
- Следовать существующей design system.
- Проверять desktop и mobile.
- Не использовать визуальный шум вместо структуры.
- UI должен быть сканируемым, аккуратным и устойчивым к длинному тексту.

## Related design skills

- `design-taste-frontend`: visually important websites, portfolios, landing pages.
- `image-to-code`: generate reference images, analyze, then implement.
- `redesign-existing-projects`: upgrade an existing website/app.
- `imagegen-frontend-web`: generate website section references.
- `brandkit`: generate brand identity boards.

## Verification

- Run app.
- Open in browser.
- Check desktop viewport.
- Check mobile viewport.
- Fix overlap, clipping, unreadable text.
