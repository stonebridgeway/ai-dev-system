# Галактика знаний

[← README](../../README.ru.md) · [Рабочий процесс](WORKFLOW.md) · [Возможности](CAPABILITIES.md) · [Ограничители](GUARDRAILS.md)

Хранилище в виде галактики, по которой можно летать. Замена графу Obsidian.

Obsidian расставляет заметки по ссылкам. Заметке, на которую никто не
ссылается, деваться некуда: она уходит во внешнее кольцо. В хранилище, полном
сгенерированных каталогов, туда уходит большая часть заметок. Галактика
расставляет заметки так, как галактика word2vec расставляет слова: каждая
заметка и каждый скилл — звезда рядом с ближайшими соседями **по смыслу**.
Похожие заметки складываются в созвездия, даже если их никто не связал
ссылками. Вики-ссылки тоже на месте: они нарисованы тёплыми линиями, так что
ничего из того, что показывал граф, не пропадает.

Навигация повторяет [Software Galaxies](https://github.com/anvaka/pm) Андрея
Кащи. На этом же движке сделана галактика word2vec
[vectorspace](https://github.com/standardgalactic/vectorspace). WASD — полёт,
мышь — обзор, положение камеры хранится в адресной строке.

## Как построить

```bash
cd ai-dev-mcp-server
npm run galaxy                                   # все заметки и скиллы
node bin/ai-dev.mjs galaxy knowledge workflows   # только эти области
```

Вне клона это та же команда `ai-dev galaxy [scope...]`, запущенная так, как ваша
установка запускает `ai-dev` ([Установка](INSTALL.md)). Или попросите агента вызвать
`render_knowledge_galaxy` (профиль `memory`). В обоих случаях получается один файл
в хранилище:

```
01-system/Knowledge Galaxy.html
```

Откройте его в любом браузере с WebGL. Он работает прямо с диска и без
интернета. Перестраивайте его, когда хранилище изменилось: команда сначала
обновляет поисковый индекс. На встроенном сиде (674 документа) весь прогон
занимает 2,3–2,5 секунды, когда индекс строится с нуля, и 1,2–1,3 секунды, когда
он актуален, на Xeon 2,1 ГГц — оба числа команда печатает сама, как `documents` и
`seconds`.

Параметры инструмента:

- `scopes`: `knowledge`, `skills`, `workflows`, `quality`, `projects`.
- `neighbors`: от 3 до 24, по умолчанию 8. Чем больше, тем плотнее и круглее
  скопления.
- `refresh_index`: по умолчанию `true` — сначала обновляется поисковый индекс;
  `false` рисует индекс как есть.
- `obsidian_vault`: имя хранилища для кнопки «Открыть в Obsidian». По
  умолчанию — имя папки хранилища.
- `seed`: одно и то же хранилище с одним и тем же seed всегда даёт одну и ту же
  галактику.

## Как летать

| Клавиша | Действие |
| --- | --- |
| `W` / `S` | вперёд / назад |
| `A` / `D` | влево / вправо |
| `R` / `F` | вверх / вниз |
| `Q` / `E` | крен |
| `↑` `↓` `←` `→` | поворот |
| `Shift` | в четыре раза быстрее |
| перетаскивание мышью | осмотреться |
| колесо | вперёд / назад |
| `Пробел` | руление: корабль поворачивает к курсору, тащить мышь не нужно |
| клик / двойной клик | выбрать звезду / полететь к ней |
| `L` | связи вкл / выкл |
| `T` | подписи вкл / выкл |
| `C` | цвет: созвездия → тип заметки → белый |
| `+` / `−` | крейсерская скорость |
| `0` / `Home` | обзор |
| `/` или `Ctrl+K` | поиск |
| `Esc` | снять выделение |
| `H` или `?` | раскладка клавиш на экране |

Клавиши читаются по физическому положению. С русской раскладкой `W` — всё та же
клавиша с буквой `Ц`, и корабль летит.

На сенсорном экране: проведите пальцем, чтобы осмотреться. Удерживайте один
палец — полёт вперёд, два — назад. Тап выбирает звезду.

## Что на экране

- **Звезда** — заметка, скилл или файл проекта из поискового индекса. Скилл с
  карточкой — одна звезда, а не две: индекс схлопывает эту пару в один
  результат поиска, и галактика схлопывает её так же.
- **Размер звезды** — сколько у неё соседей. Звезда, на которую похожи многие
  заметки, большая.
- **Созвездие** — сообщество в графе соседей (модулярность Louvain). Его
  название — пара слов из заголовков, самых характерных для него. Название
  вычисляется, а не пишется вручную, поэтому у созвездия из названий брендов
  его может не быть.
- **Линии.** По умолчанию рисуются только короткие связи: все сразу
  превращаются в клубок. Порог задаёт `ml` в адресе. Вики-ссылки рисуются
  всегда, тёплым цветом. При выборе звезды рисуются все её связи, а остальное
  приглушается.
- **Карточка** выбранной звезды показывает ближайших соседей со степенью
  сходства, связанные ссылками заметки, начало текста и кнопку
  **«Открыть в Obsidian»**.

Положение звёзд — раскладка, а не измерение. Две звезды рядом похожи. Две
далёкие звезды только *менее* похожи, и насколько — не сказано.

## Откуда берутся координаты

Галактика берёт лучшие векторы, какие есть в поисковом индексе:

- векторы **BGE-M3** — для каждого документа, у которого они есть. Их строит
  `npm run setup -- --model` ([Установка](INSTALL.md));
- **векторы ключевых слов** из индекса — для остальных. Они взвешены так, чтобы
  слово, которое есть в каждой заметке, не стягивало их все в одну точку.

Строка состояния показывает, в каком пространстве вы находитесь:
`пространство BGE-M3`, `пространство ключевых слов` или оба. Галактика на
ключевых словах полезна. На BGE-M3 — лучше: она группирует заметки по смыслу,
а не по общим словам.

Как это устроено внутри. Каждый документ связывается с восемью ближайшими
соседями. Поиск идёт в 96-мерном главном подпространстве, а найденные
кандидаты пересчитываются точно. На встроенном сиде так находится 98% настоящих
восьми соседей примерно за половину времени точного поиска. Потом результат
раскладывает силовая раскладка с физикой `ngraph.forcelayout`. Она стартует с
главных координат документов, а пружины между созвездиями слабее пружин внутри них.

## Что есть в файле и чего он не делает

В странице есть заголовки, пути в хранилище и первые 240 символов каждого
нарисованного документа. **Кто получил файл, получил и это.**

Страница не делает никаких запросов. Она не загружает ни скриптов, ни шрифтов,
ни картинок, а её Content-Security-Policy (из хешей двух её собственных
встроенных блоков) отказала бы в загрузке, если бы она попыталась. Текст из
хранилища попадает на страницу через `textContent` и никогда не разбирается как
HTML, поэтому ни один заголовок заметки не может стать разметкой.

## Ограничения

- **Время растёт как квадрат размера хранилища.** Замер на Xeon 2,1 ГГц:
  674 документа встроенного сида — 2,3–2,5 с вместе с индексом; 10 000 и 20 000
  документов — синтетических, из собственных векторов сида — 33 с и 104 с только
  на граф, созвездия и раскладку, и около трёх четвертей этого уходит на граф
  соседей.
- **Одна галактика рисует не больше 20 000 документов.** Если больше, сузьте
  её через `scopes`.
- **Больше примерно 10 000 документов — запускайте из командной строки.**
  MCP-клиент может прервать вызов раньше: тайм-аут запроса по умолчанию в MCP
  SDK — 60 секунд.
- **Нужен WebGL.** Без него страница прямо так и скажет, а не покажет пустое
  небо.
